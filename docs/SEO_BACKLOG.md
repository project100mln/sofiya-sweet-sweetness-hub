## Карточка любого пункта в журнале

До исполнения: ID, цель, scope/exclusions, зависимости, ответственный, base SHA,
файлы/URL, тесты, риски, откат, стоп-условия. После: candidate SHA, команды/ссылки,
результаты/пропуски, статус, следующий шаг. Требование → ID → тест → release gate.
Code checks: npm run format:check / lint / typecheck / test / review:kk:check,
build, verify:i18n:ssr и релевантные Playwright. Читать команды перед запуском:
общий npm run check включает Cloudflare dry-run. Не запускать production под видом QA.
Docs-only: формат, ссылки/ID, git diff --check. Прежний CI не доказывает новый SHA.
Откат ветки: отдельный revert, не force push. Production: предыдущая Cloudflare
версия/артефакт и согласованные границы отката. Стоп: доступ/оплата/разрешение,
неподтверждённый бизнес-факт, перевод, чужой проект или риск потери пользовательских правок.
