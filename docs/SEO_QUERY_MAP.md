# SOFIYA — запросы и целевые страницы

Дата проверки: 2026-09-23. SEO-06 DONE в границах карты намерений и URL.
Это рабочая семантика по ассортименту, публичному поиску и источникам, а не
измеренная частотность или отчёт о позициях Google из Шымкента. GSC недоступен.
Приоритеты ниже — экспертная последовательность реализации, не прогноз трафика.

## Решения по бренду

Официальное имя — SOFIYA. «София» — русскоязычный вариант для естественного
пояснения в тексте о компании; отдельные страницы вариантов написания не нужны.
«Сафия / Safia / Safiya» вести отдельным наблюдаемым кластером. На официальном
сайте Safia указаны собственные филиалы в Шымкенте: это не доказанная опечатка SOFIYA.
Не добавлять Safia как alternateName нашей организации, не обещать первенство по
чужому бренду, не создавать страницы, выдающие SOFIYA за Safia.
В найденном публичном каталоге SOFIYA уже есть товар «София Принцесса»;
его название не означает системную проработку русскоязычного бренда.

У страниц есть соответствующие пары /kk (для главной /kk).
Смысловые KK-кластеры: торттар, тапсырыспен торттар, пісірмелер, десерттер,
тәттілер, кондитерлік, дүкендер/мекенжайлар + Шымкент. Это исследовательские
группы, а не утверждённые формулировки для публикации; новые тексты — SEO-05.

## Что сделать следующим — SEO-07

1. Усилить главную понятным текстом о SOFIYA как кондитерской в Шымкенте,
   не менять фирменный слоган и не создавать дублирующую /konditerskaya.
2. Дать естественное пояснение SOFIYA («София») на /about, без перечисления опечаток.
3. Добавить тему сладостей в полезный текст /catalog/desserts и связи с категориями;
   не создавать /sladosti с тем же ассортиментом без подтверждённого отдельного спроса.
4. Сохранить различие готовых тортов и индивидуального заказа в title/H1/ссылках.
5. Отдельно проверить бренд в footer: текущий текст содержит SOFIYA Sweet, хотя
   владелец указал официальное имя SOFIYA. Не переписывать утверждённый KK перевод
   в рамках незаявленной косметики; учитывать прямое решение владельца о бренде.

## Проверка после получения данных

SEO-01: последние 7 полных доступных дней против предыдущих 7, плюс 28 дней при
малом объёме. SEO-14: таблица query × page × device, CTR с учётом позиции и бренда.
Несколько страниц на один запрос — повод проверить намерения, не доказательство
каннибализации. Поддерживающие страницы могут ранжироваться без дефекта.
Переоценить гипотезу «сладости»: выдача включает более широкий ассортимент,
поэтому частотность, реальные запросы и конверсии нужны до создания нового URL.
