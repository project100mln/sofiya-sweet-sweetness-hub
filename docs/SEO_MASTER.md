## Измерение и критерии

Последние 7 ПОЛНЫХ доступных дат GSC против предыдущих 7, одинаковые web/страна/
устройство/ресурс. Записывать даты и свежесть. Clicks/impressions — суммы;
CTR = clicks/impressions, изменение в п.п.; позиция GSC или взвешенная по показам,
меньше лучше. При нулевой базе процент роста не вычислять. Не суммировать позиции/CTR.
Query totals могут отличаться от общих из-за скрытых запросов. Кластеры пересекаются.
Для малого объёма добавить 28 дней; не объявлять колебание эффектом релиза.
Рабочий порог приоритизации CTR: 100 показов/28 дней (допущение, не стандарт),
с учётом позиции, бренда и устройства. Несколько URL на запрос — кандидат для
проверки намерений, не автоматически каннибализация. Клик WhatsApp ≠ заявка ≠ продажа.
Цели роста установить после baseline; ТОП-1/сроки индексации не гарантировать.

## Рабочий цикл

Прочитать checkpoint → обновить факты → выбрать ID → выполнить → проверить → обновить
backlog/log/checkpoint → отчитаться. Один активный пункт; не повторять дорогое QA
неизменённого SHA без причины. Отчёт: выполнено/evidence/не выполнено/блокер/3 приоритета.
Различать код готов, preview проверен, опубликовано, Google индексирует, эффект измерен.
Существующий weekly SEO мониторинг не дублировать. Непрерывная память не гарантируется:
постоянные источники нужно читать. Текст инструкции ChatGPT не равен изменению настроек.
